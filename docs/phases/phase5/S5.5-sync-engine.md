# S5.5 — Sync Engine & Local Reconciliation

## Objective
Build a transport-independent engine for local synchronization.

## Components
- \ISyncEngine\ (Domain) — interface for manifest, selection, application
- \SyncManifestBuilder\ (Infrastructure) — builds manifest from active entities + tombstones
- \SyncEngine\ (Infrastructure) — orchestrates reconciliation and change application

## Key Behaviors
- Manifest: compact \SyncObjectSummary[]\ with state hashes
- Change selection: filters by remote's known version
- Application order: Employees/Assets first, then Assignments
- Idempotency: checks \ChangeId\ before applying
- Dependencies: rejects assignments referencing missing entities with \DomainValidationException\
- Checkpoints: advance only after successful application
